LAKESIDE HAVEN HOTEL — 8-PAGE HTML WEBSITE

Files included:
index.html — Home
rooms.html — Rooms and rates
dining.html — Dining and sample menu
facilities.html — Facilities
gallery.html — Photo gallery
offers.html — Offers
about.html — About the hotel
contact.html — Contact and enquiry form

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a browser.
3. Use the navigation hyperlinks to move between pages.
4. Images load from Unsplash, so an internet connection is needed to display them.
5. The hotel, contact details, prices and offers are fictional examples for a school project.
6. The pages include hyperlink tags, tables, bold tags, headings, forms and image tags.
7. No HTML comment tags are used.

Open the .html files in VS Code to edit them.
